功能特性 / Features

  • 完整中文界面 / Complete Chinese Interface
  • 保留英文版本 / Preserved English Version
  • 动态语言切换 / Dynamic Language Switching
  • 所有UI元素翻译 / All UI Elements Translated
  • 错误消息本地化 / Localized Error Messages

使用方法 / Usage

  1. URL参数控制语言 / URL parameter controls language:
    • ?lang=zh - 中文界面 / Chinese Interface
    • ?lang=en - 英文界面 / English Interface (默认/default)
  2. 所有功能保持不变 / All functionality remains unchanged
  3. 用户体验优化 / Enhanced user experience
