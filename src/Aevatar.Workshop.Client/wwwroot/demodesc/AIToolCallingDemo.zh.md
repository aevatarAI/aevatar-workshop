# AI 工具调用演示

此演示展示了 AIGAgentBase 如何通过 Semantic Kernel 框架使 AI 代理能够发现并使用其他 GAgent 作为工具。

## 功能特点

### 🔧 可用工具

- **MathGAgent（数学计算代理）**：执行复杂的数学计算
  - 支持基本算术、三角函数、对数等
  - 处理自然语言数学表达式，如"16的平方根"
  
- **TimeConverterGAgent（时间转换代理）**：处理时间相关操作
  - 在不同时区之间转换时间
  - 显示任何时区的当前时间
  - 计算时间差

### 🤖 工作原理

1. **自动发现**：AI 代理通过 `IGAgentService` 自动发现可用的 GAgent
2. **工具注册**：每个 GAgent 的事件处理器都注册为 Kernel 函数
3. **智能选择**：LLM 根据您的请求决定何时以及如何使用这些工具
4. **自然语言**：只需用中文提问 - AI 会自动判断使用哪个工具

### 💡 示例查询

尝试向 AI 代理提出如下问题：
- "250的15%是多少？"
- "计算144的平方根加上25"
- "东京现在几点？"
- "把美东时间下午3点转换成太平洋时间"
- "上午9点到下午5点30分之间有多少小时？"
- "计算：(12 + 8) * 3 / 2"

### 🚀 开始使用

1. **初始化代理**：选择您的 LLM 系统并点击"初始化"
2. **提出问题**：输入任何数学或时间相关的问题
3. **观察工具运行**：查看 AI 使用了哪些工具及其结果
4. **查看历史**：检查工具调用历史以了解 AI 的决策过程

AI 代理会解释它正在使用哪个工具以及原因，让您了解其决策过程的透明度。
