# MultiGAgentDemo

- Multi-agent "Guess the Number" game: Alice picks a secret number (default 42, you can choose 1-100), Bob tries to guess it via events.
- Enter your secret number and select the LLM system before running the demo.
- All conversations and guesses are shown in the chat panel below, auto-refreshing every 5 seconds.
- Experience multi-agent collaboration and message flow.
