# MCP 演示

这个演示展示了模型上下文协议（MCP）与 Aevatar GAgents 框架的集成。MCP 是一个让 AI 助手通过标准化接口与外部工具和服务交互的协议。

## 概述

MCP GAgent 允许您：
- 配置并连接到多个 MCP 服务器
- 从已连接的服务器发现可用工具
- 使用指定参数执行工具
- 查看服务器连接状态和工具调用历史

## 可用的 MCP 服务器

此演示包含三个示例 MCP 服务器：

### 1. 文件系统服务器
- 访问和操作 `/tmp` 目录中的文件
- 读取、写入和列出文件
- 适用于基于文件的操作

### 2. 时间服务器
- 获取不同时区的当前时间
- 在时区之间转换时间
- 执行时间相关的计算

### 3. 内存服务器
- 存储和检索键值对
- 跨会话维护持久内存
- 适用于状态管理

## 使用方法

1. **选择服务器**：选择要连接的 MCP 服务器
2. **初始化**：点击初始化按钮建立连接
3. **查看状态**：检查服务器连接状态和可用工具
4. **调用工具**：选择工具，以 JSON 格式提供参数并执行
5. **查看历史**：跟踪所有工具调用及其结果

## 技术细节

- MCP 服务器作为独立进程运行，使用 stdio 通信
- 连接后动态发现工具
- 所有工具调用都通过 GAgent 系统进行事件驱动
- 结果异步返回并实时显示
