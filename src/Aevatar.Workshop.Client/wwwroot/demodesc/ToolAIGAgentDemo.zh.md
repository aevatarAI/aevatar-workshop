# ToolAI GAgent 演示

这个演示展示了 **ToolAIGAgent** - 一个智能的AI协调器，它可以调用系统中的其他代理来完成复杂任务。它演示了大型语言模型（LLM）如何通过工具调用机制智能地编排多个代理。

### 什么是 ToolAIGAgent？

**ToolAIGAgent** 是一个高级AI代理，它扩展了基础的 `AIGAgentBase`，具备工具调用能力。它与 Semantic Kernel 集成，为LLM提供以下能力：

- **分析复杂任务** 并将其分解为步骤
- **调用系统中的其他GAgent** 作为工具
- **协调多个代理** 以实现综合结果
- **提供智能路由** 将子任务分配给专门的代理

### 工作原理

1. **任务接收**：ToolAIGAgent 从用户接收复杂任务
2. **任务分析**：LLM 分析任务并确定需要哪些步骤
3. **工具选择**：基于分析，它决定调用哪些工具（其他GAgent）
4. **执行**：它使用特定指令调用适当的GAgent
5. **结果整合**：它将来自不同代理的结果组合成综合响应

### 可用工具

ToolAIGAgent 可以访问几个内置工具：

- **call_gagent**：通过标识符调用系统中的任何GAgent
- **research**：调用ResearcherGAgent进行信息收集任务
- **write**：调用WriterGAgent进行内容创建任务
- **record**：调用RecorderGAgent记录重要信息

### 示例工作流程

当你给ToolAIGAgent一个任务，比如*"写一份关于2024年人工智能的综合报告"*，它可能会：

1. 首先调用 **research** 工具收集关于2024年AI趋势的信息
2. 然后调用 **write** 工具基于研究创建结构化报告
3. 最后调用 **record** 工具记录任务完成情况

### 优势

- **智能任务分解**：复杂任务自动分解
- **专业代理利用**：每个子任务由最合适的代理处理
- **无缝集成**：所有代理作为统一系统协同工作
- **透明过程**：你可以观察决策制定和协调过程
