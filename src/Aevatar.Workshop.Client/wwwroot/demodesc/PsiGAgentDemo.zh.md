# PsiGAgent 演示

## 概述
PsiGAgent演示展示了一个革命性的自组织AI代理系统，它可以根据任务的复杂性动态调整其操作模式。与传统的AI代理不同，PsiGAgent会自动决定是作为协调器（Orchestrator，将任务委派给专门的子代理）还是作为专门化代理（Specialized，直接执行特定任务）运行。

## 主要特性
- **自组织能力**：代理自动确定最佳操作模式
- **动态层级结构**：复杂任务触发子代理层级的创建
- **实时可视化**：观察代理网络在处理任务时的增长和演变
- **灵活的任务处理**：从简单查询到复杂的多步骤项目

## 工作原理
1. **任务分析**：收到任务后，PsiGAgent分析其复杂性和需求
2. **模式选择**：基于分析结果，它决定：
   - **协调模式**：分解复杂任务并委派给专门的子代理
   - **专门化模式**：直接处理特定的、明确定义的任务
3. **动态扩展**：根据需要，代理可以创建子代理，形成任务解决层级
4. **结果聚合**：协调器代理收集并综合来自子代理的结果

## 使用场景示例
- **派对策划**：分解为场地研究、餐饮选择、娱乐策划等子任务
- **研究项目**：创建专门的代理进行数据收集、分析和总结
- **内容创作**：将研究、写作和编辑委派给不同的专门代理
- **问题解决**：将复杂问题分解为可管理的子问题

## 技术亮点
- 基于Orleans Actor框架的分布式代理管理
- 使用Semantic Kernel提供AI能力
- 实时状态同步和可视化
- 自动代理创建的层级任务分解

## 开始使用
1. 点击"创建新代理"初始化根PsiGAgent
2. 输入任务或从示例任务中选择
3. 观察代理分析任务并创建执行策略
4. 实时观察代理层级可视化的更新
5. 在聊天历史中查看最终结果

这个演示代表了自主AI系统的重大进步，展示了代理如何自组织来处理复杂的、多方面的挑战，而无需为每个场景进行显式编程。
