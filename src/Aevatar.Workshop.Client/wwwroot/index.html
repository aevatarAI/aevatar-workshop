What is SystemLLMConfigs? How to configure?
SystemLLMConfigs is the section in appsettings.json where you configure your LLM (Large Language Model) provider.

  • ProviderEnum: The provider type, e.g. OpenAI or Azure.
  • ModelIdEnum: The model identifier, e.g. OpenAI or your provider's model ID.
  • ModelName: The name of the model to use, e.g. gpt-4o or gpt-3.5-turbo.
  • Endpoint: The API endpoint URL for your LLM provider.
  • ApiKey: Your secret API key for accessing the LLM service.
How to get these values?
- For OpenAI: Get your API key here.
- For Azure OpenAI: See Azure OpenAI setup guide.
- For more details, see Aevatar Workshop Configuration Docs.
