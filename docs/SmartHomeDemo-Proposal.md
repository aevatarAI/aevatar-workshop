# 智能家居演示 - Aevatar 简化入门

## 🎯 演示目标

创建一个直观、贴近生活的演示，让用户通过智能家居控制场景立即理解 Aevatar 多智能体系统的强大功能。

## 🏠 概念概述

想象用自然语言控制整个家居。这个演示模拟了一个智能家居系统，其中不同设备是通过事件通信的独立智能体，展示了：

- **多智能体协作**：每个设备都是自主智能体
- **事件驱动架构**：设备响应事件，而非直接命令
- **AI 集成**：通过 Semantic Kernel 实现自然语言理解
- **虚拟 Actor 模型**：每个设备独立维护自己的状态
- **事件溯源**：完整记录所有家居活动历史

## 🎭 核心角色（GAgents）

### 1. HomeAIGAgent（大脑）🤖
- **角色**：自然语言接口
- **能力**：
    - 理解"打开客厅的灯"等命令
    - 将意图转换为结构化事件
    - 使用 Semantic Kernel 进行 NLP
- **价值展示**：展示 AI 集成而不增加复杂性

### 2. LightGAgent（设备）💡
- **状态**：开/关，亮度（0-100%）
- **事件**：
    - 处理：`TurnOnCommand`、`TurnOffCommand`、`SetBrightnessCommand`
    - 发布：`LightStateChanged`
- **价值**：具有清晰行为的简单状态机

### 3. ThermostatGAgent（设备）🌡️
- **状态**：当前温度、目标温度、模式（制热/制冷/关闭）
- **事件**：
    - 处理：`SetTemperatureCommand`、`ChangeModeCommand`
    - 发布：`TemperatureChanged`、`ModeChanged`
- **价值**：展示复杂状态管理

### 4. SecurityGAgent（设备）🔒
- **状态**：布防/撤防、检测到移动
- **事件**：
    - 处理：`ArmCommand`、`DisarmCommand`
    - 发布：`SecurityStateChanged`、`MotionDetected`
- **价值**：演示响应式行为

### 5. HomeCoordinatorGAgent（协调器）🎯
- **角色**：管理所有设备的父智能体
- **能力**：
    - 将 AI 的命令路由到适当的设备
    - 实现"场景"（如"晚安"关灯、设置温度、布防安全系统）
- **价值**：展示父子关系和协调能力

## 💫 用户体验流程

### 简单交互
1. 用户输入："打开灯"
2. AI 理解意图 → 发布 `DeviceControlIntent` 事件
3. 协调器接收事件 → 向 LightGAgent 发布 `TurnOnCommand`
4. 灯打开 → 发布 `LightStateChanged` 事件
5. UI 更新显示灯已打开
6. 事件记录器记录一切

### 复杂交互（场景）
1. 用户输入："晚安"
2. AI 识别场景 → 发布 `SceneActivationIntent` 事件
3. 协调器编排：
    - 向所有灯发布 `TurnOffCommand`
    - 向恒温器发布 `SetTemperatureCommand(20°C)`
    - 向安全系统发布 `ArmCommand`
4. 所有设备响应状态变化事件
5. UI 显示协调的变化
6. 事件日志显示事件级联

## 🎓 教育价值

### 1. 立即理解
- **之前**："什么是多智能体系统？"
- **之后**："哦，每个设备就像一个小程序，可以和其他设备对话！"

### 2. 事件驱动架构
- **可视化**：实时查看事件在智能体之间流动
- **交互式**：点击查看事件详情、发送者、接收者

### 3. 虚拟 Actor 模型
- **演示**：即使其他设备故障，每个设备仍能继续工作
- **优势**：展示韧性 - "即使恒温器崩溃，灯光仍然正常工作！"

### 4. 事件溯源
- **功能**：时间旅行查看家居状态
- **UI**：滑块重放一天的事件
- **价值**："准确查看供暖何时以及为何开启"

### 5. AI 集成
- **简单**：自然输入，系统理解
- **强大**：展示 AI 如何将意图转换为特定设备命令
- **可扩展**："轻松添加自己的命令！"

## 🚀 实现简单性

### 最小代码示例
```csharp
// 用户视角：只需一行代码添加新设备！
public interface ILightGAgent : IStateGAgent<LightState> { }

[GAgent]
public class LightGAgent : GAgentBase<LightState>, ILightGAgent
{
    [EventHandler]
    public Task HandleTurnOn(TurnOnCommand cmd)
    {
        RaiseEvent(new LightStateChanged { IsOn = true });
        return Task.CompletedTask;
    }
}
```
